# Управление робособакой: MPC + RL

Цель проекта — реализовать управление робособакой с помощью MPC и обучения с подкреплением (RL), проверить каждый подход отдельно, а затем разработать совместный вариант. Сначала работа ведётся в симуляции MuJoCo на модели Unitree A1. В дальнейшем планируется добавить манипулятор и перейти к управлению всей системой.

## Части проекта

### 1. Отдельное управление через MPC

MPC использует математическую модель робота, прогнозирует движение на короткий промежуток времени и рассчитывает силы опоры с учётом ограничений. Эти силы переводятся в моменты моторов.

На этом этапе нужно проверить стойку, перенос веса, перестановку лап и ходьбу. Эта часть также служит базовым вариантом для сравнения с RL и совместным управлением.

### 2. Отдельное управление через RL

RL-политика должна обучиться управлять собакой в симуляции по заданной цели и наблюдениям о состоянии робота.

Задача этого этапа — получить самостоятельный контроллер и сравнить его с MPC на одинаковых сценариях: движение по команде, сохранение равновесия и реакция на внешние воздействия.

### 3. Совместное управление MPC + RL

После проверки отдельных подходов планируется объединить их в одном контроллере. MPC должен учитывать модель движения и ограничения, а RL — помогать компенсировать неточности модели и адаптировать управление к условиям движения.

Конкретный способ взаимодействия MPC и RL предстоит выбрать и проверить экспериментально. Главный вопрос — даёт ли их совместная работа измеримое улучшение по сравнению с каждым подходом отдельно.

### 4. Собака с манипулятором

Следующий этап — отдельно отработать управление манипулятором, затем объединить его с управлением собакой. Нужно будет учитывать, как движения руки и переносимый груз влияют на центр масс, нагрузку на лапы и устойчивость всей системы.

Вариант с отдельными RL-политиками для собаки и манипулятора и их координацией через MPC рассматривается как один из возможных подходов. Окончательная архитектура пока не зафиксирована.

## Что сравниваем

- Точность выполнения команды движения.
- Устойчивость и наклоны корпуса.
- Реакцию на толчки и изменение нагрузки.
- Соблюдение ограничений моторов и контактов.
- Время вычисления управления.

Для корректного сравнения отдельные и совместные контроллеры должны проверяться на одной модели и одинаковых сценариях.

## Текущее состояние

Реализован базовый MPC для отдельной собаки: стойка, перенос веса, подъём лапы и медленная ходьба по ровному полу в MuJoCo. Пройдены проверки движения вперёд, назад, в стороны и сценария с толчком.

RL, совместное управление MPC + RL и манипулятор относятся к следующим этапам. Результаты на механическом роботе пока не получены.
